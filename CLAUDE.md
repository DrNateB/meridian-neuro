# Meridian Neuro

## Stack
- Next.js 14 (App Router)
- React 18, TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion

## Structure
- `app/(pages)/` — Route group for all pages (about, research, access, grants, get-involved, contact)
- `components/layout/` — Navbar, Footer
- `components/sections/` — Page sections (hero, features, etc.)
- `components/ui/` — shadcn/ui components
- `lib/constants.ts` — Site-wide constants (DONATE_URL, etc.)
- `lib/utils.ts` — shadcn/ui utility (cn)
